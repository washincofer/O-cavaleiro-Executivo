# Asset Integration Checklist

## Character

- [ ] PNG RGBA.
- [ ] Native 1x.
- [ ] Nearest/Point.
- [ ] Sem trim.
- [ ] 4 direções.
- [ ] Down/Left/Right/Up.
- [ ] Pivot de base.
- [ ] Pixel QA.
- [ ] Eventos configurados fora da arte.
- [ ] Runtime contém apenas APPROVED.

## Environment

- [ ] Tile size medido, não inferido.
- [ ] Atlas grid consistente.
- [ ] Anchor dos props definido.
- [ ] Footprint definido.
- [ ] Movement collision definido.
- [ ] Projectile collision definido.
- [ ] Navigation definido.
- [ ] Layer / Y-Sort definido.
- [ ] Nenhum prop invade rotas/spawns.
- [ ] Greybox funcional continua equivalente.
