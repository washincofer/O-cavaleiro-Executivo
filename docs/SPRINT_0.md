# Sprint 0 — Laboratorio de Gameplay

## Stack
- Godot 4.x
- GDScript
- Resolucao interna: 320x180
- Escala inicial do protagonista: 48 px
- Tiles de referencia: 16x16

## DEV — primeira meta
Executar a sala e validar:
- movimento horizontal
- pulo
- dash
- colisao com piso, balcao e plataforma
- camera
- reinicio rapido com R

Controles provisórios:
- A / seta esquerda: mover esquerda
- D / seta direita: mover direita
- Espaco: pular
- K: dash
- R: reiniciar sala
- J: reservado para ataque (ainda nao implementado)

## DG — primeira meta
Produzir uma folha de escala sem arte final:
- Estagiario: ~44 px
- Espadachim: ~48 px
- Cavaleiro Executivo: ~48 px
- Coordenador: ~60 px

Validar apenas:
- silhueta
- proporcao
- leitura de arma
- diferenca hierarquica

## Checkpoint do Sprint 0
O build deve permitir entrar na Recepcao, correr, pular, fazer dash e colidir corretamente antes de implementar combate.
